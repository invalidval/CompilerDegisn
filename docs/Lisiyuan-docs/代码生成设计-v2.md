目标取向
把布尔值视为整型 (int)；不引入 <stdbool.h>，兼容老旧编译器。
将 Pascal-S 的常见运算符映射到标准 C 运算符，确保生成的表达式是可编译且语义接近 Pascal-S 的。
布尔字面量 true/false 输出转为 1/0，避免在没有布尔头文件时的编译错误。
关键设计点
运算符映射：div -> /、mod -> %、= -> ==、<> -> !=、and -> &&、or -> ||。
数据类型映射：DataType::Boolean 仍映射为 int；不引入布尔类型。
头文件与字面量：wrapAsCProgram 只包含 stdio.h，移除对 <stdbool.h> 的依赖；常量布尔字面量统一为 1/0。
输入/输出：read/write 使用现有格式化（%d、%lf、%c 等），布尔按 0/1 处理，输出也以 0/1 形式呈现。
风险控制
需要在现有代码中避免对 bool 的直接依赖，所有涉及布尔的代码路径都回退到整数表示。
后续若环境允许，Plan A 的布尔真/假表达（true/false 显式布尔类型）仍可切换回去。
