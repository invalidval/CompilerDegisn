新增一个一键运行测试的脚本，方便一次性编译并执行测试集中的所有测试子集。

新增内容:

文件: CompilerDegisn/test/run_all_tests.sh
功能要点：
构建项目
依次运行：lexer 测试、parser 测试、semantic 测试、全量测试、开放集测试
全部测试完成后输出提示
如何运行

快速单行执行（推荐用于一次性测试）：
在终端（Windows 的 Git Bash / Linux / macOS）执行： bash CompilerDegisn/test/run_all_tests.sh
备选：先设为可执行再执行
在 Linux/macOS 上： chmod +x CompilerDegisn/test/run_all_tests.sh ./CompilerDegisn/test/run_all_tests.sh
也可将输出重定向到日志，便于排错： bash CompilerDegisn/test/run_all_tests.sh | tee test_all.log
运行前的注意事项

该脚本默认使用相对路径进行构建与测试，因此请在包含该项目根目录的工作目录中执行（例如从项目根目录执行上面的命令，或先 cd 到项目根再执行）。
依赖环境：
需要具备 bash 环境（Windows 下可用 Git Bash、WSL，或类 Unix 环境）。
构建脚本 (CompilerDegisn/scripts/build.sh) 需要 cmake/make 等工具，确保已安装并在 PATH 中可用。
失败处理：
该脚本采用 set -euo pipefail，遇到错误会立即停止执行。若遇到某个子测试失败，请直接查看相应测试脚本的输出日志（当前标准输出会打印阶段名与错误点）。
工作原理简述

run_all_tests.sh 以项目根目录为基准，顺序执行以下步骤：
构建编译产物
lexer 相关单元测试
parser 测试
semantic 测试
全量测试（test/run_tests.sh）
开放集测试（test/run_openset_check.sh）
这样可以快速验证 Plan B 的实现是否稳健覆盖了核心路径（词法、语法、语义、代码生成，全量用例与边界用例）。
