### 1.2 Token 接口定义（需求分析 P.17）

**需求规范**:
```c
typedef struct {
    TokenType type;
    char* value;      // 标识符/常数具体值
    int line;         // 行号
    int column;       // 列号
} Token;
```

**实现情况**:
```cpp
struct Token {
    TokenType type;
    std::string lexeme;  // 原始文本 + 语义值通道
    int line;
    int column;
};
```

**对标分析**:
- ✅ `type` 完全对应
- ✅ `lexeme` 包含源文本，语义值通过 `yylval` (Bison 通道) 传递
- ✅ `line/column` 完全对应，均 1-based
- ℹ️ 实现采用 C++ string 替代 char*，但兼容性无影响（词法契约 v1 第 3.3 节已说明）

**对标结论**: ✅ **完全兼容** - 结构体对标需求，可选扩展不违反原约定。
