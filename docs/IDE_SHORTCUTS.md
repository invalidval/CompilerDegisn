# PASCC IDE 快捷键参考

## 保存文件的多种方式

由于 macOS 终端的限制，我们提供了多种保存方式：

### 方式 1：F2 键（推荐）
```
按 F2 → 保存当前文件
```
这是最可靠的方式，在所有终端中都能工作。

### 方式 2：Ctrl+S（需要禁用流控制）
```
按 Ctrl+S → 保存当前文件
```
使用 `bash scripts/run_ide.sh` 启动时会自动禁用流控制。

### 方式 3：命令模式（类似 vim）
```
按 Ctrl+X → 输入命令 → Enter
```

可用命令：
- `:w` 或 `:write` - 保存文件
- `:q` 或 `:quit` - 退出（有未保存更改会提示）
- `:wq` 或 `:x` - 保存并退出
- `:w filename.pas` - 另存为

## 启动方式

### 推荐方式（自动禁用流控制）
```bash
bash scripts/run_ide.sh
bash scripts/run_ide.sh test/close_set/00_main.pas
```

### 手动禁用流控制
如果直接运行 Python 脚本，需要先禁用流控制：
```bash
stty -ixon
python3 scripts/pascc_ide.py test.pas
```

### 恢复流控制（退出 IDE 后）
```bash
stty ixon
```

## 常见问题

### Q: 为什么 Ctrl+S 不工作？

**A:** 在 Unix/Linux 终端中，Ctrl+S 默认用于流控制（XOFF），会暂停终端输出。解决方案：

1. 使用 `bash scripts/run_ide.sh` 启动（推荐）
2. 或手动运行 `stty -ixon` 禁用流控制
3. 或使用 F2 键代替

### Q: 为什么 Cmd+S 不工作？

**A:** macOS 的 Cmd 键是系统级快捷键，终端程序无法捕获。请使用 F2 或 Ctrl+S。

### Q: 如何恢复被 Ctrl+S 冻结的终端？

**A:** 按 Ctrl+Q 可以恢复（这是 XON 信号）。

### Q: 按了 Ctrl+S 后终端卡住了怎么办？

**A:** 这说明流控制没有被禁用。按 Ctrl+Q 恢复，然后：
```bash
# 退出 IDE
# 运行以下命令
stty -ixon
# 重新启动 IDE
bash scripts/run_ide.sh
```

## 工作流示例

### 示例 1：使用 F2 保存
```
1. 启动 IDE: bash scripts/run_ide.sh
2. 编写代码
3. 按 F2 保存
4. 按 F5 编译
5. 按 F9 运行
```

### 示例 2：使用命令模式
```
1. 启动 IDE: bash scripts/run_ide.sh test.pas
2. 编写代码
3. 按 : 进入命令模式
4. 输入 w 并按 Enter 保存
5. 按 F5 编译
6. 按 : 输入 q 退出
```

### 示例 3：快速编译运行
```
1. 打开文件: bash scripts/run_ide.sh test.pas
2. 修改代码
3. 按 F2 保存
4. 按 F5 编译（自动保存）
5. 按 F9 运行
6. 查看右侧输出面板
```

## 提示

1. **F2 是最可靠的保存方式**，在所有情况下都能工作
2. **使用启动脚本**（`run_ide.sh`）可以避免流控制问题
3. **命令模式**（按 :）提供了类似 vim 的体验
4. **F5 编译前会自动保存**，所以可以直接按 F5
5. **错误行会高亮显示**，编译失败时会自动跳转到第一个错误
