# PASCC IDE 开发总结

## 项目概述

为 Pascal-S 到 C 编译器项目开发了一个轻量级的终端 IDE，提供代码编辑、实时编译和错误导航功能。

## 已完成的功能

### 核心功能

1. **代码编辑器**
   - 基本文本编辑（插入、删除、换行）
   - 光标移动（方向键、Home/End、Page Up/Down）
   - 行号显示
   - 当前行高亮

2. **语法高亮**
   - Pascal-S 关键字（蓝色）
   - 注释 `{ }` （绿色）
   - 字符串 `'...'` （黄色）
   - 数字（紫色）

3. **编译集成**
   - F5 快速编译
   - 自动保存后编译
   - 实时显示编译输出
   - 错误解析和标记

4. **错误导航**
   - 错误行红色高亮
   - 自动跳转到第一个错误
   - 行号处显示错误标记
   - 输出面板显示详细错误信息

5. **运行功能**
   - F9 快速运行
   - 自动调用 GCC 编译 C 代码
   - 显示程序输出

6. **文件操作**
   - 打开文件（Ctrl+O）
   - 保存文件（F2 / Ctrl+S）
   - 另存为
   - 命令行参数支持

7. **命令模式**
   - vim 风格的命令模式（按 :）
   - 支持 :w（保存）、:q（退出）、:wq（保存并退出）
   - 支持 :w filename（另存为）

8. **用户界面**
   - 双面板布局（编辑器 + 输出）
   - 状态栏（文件名、光标位置、快捷键提示）
   - 输出面板滚动
   - 响应式布局

## 技术实现

### 架构设计

- **编辑器核心**：基于 Python curses 库
- **状态管理**：使用 dataclass 管理编辑器状态
- **语法高亮**：简单的词法分析器（tokenizer）
- **编译集成**：通过 subprocess 调用 pascc 命令行工具
- **错误解析**：正则表达式解析编译器输出

### 关键特性

1. **独立性**：不需要修改编译器代码，通过命令行接口集成
2. **轻量级**：单文件实现，无额外依赖
3. **跨平台**：支持 macOS、Linux（需要 curses）
4. **可扩展**：模块化设计，易于添加新功能

### 解决的问题

1. **快捷键冲突**
   - 问题：macOS 下 Ctrl+S 被终端流控制占用
   - 解决：
     - 启动脚本自动禁用流控制（`stty -ixon`）
     - 添加 F2 作为替代保存键
     - 提供命令模式（:w）

2. **终端兼容性**
   - 使用标准 curses API
   - 优雅处理终端尺寸变化
   - 安全的颜色初始化

3. **错误处理**
   - 解析编译器错误格式
   - 提取行号和列号
   - 在编辑器中标记错误位置

## 使用方式

### 基本使用

```bash
# 启动空白编辑器
bash scripts/run_ide.sh

# 打开指定文件
bash scripts/run_ide.sh test_ide_demo.pas

# 打开测试用例
bash scripts/run_ide.sh test/close_set/00_main.pas
```

### 快捷键

| 功能 | 快捷键 |
|------|--------|
| 保存 | F2 或 Ctrl+S |
| 编译 | F5 |
| 运行 | F9 |
| 命令模式 | : |
| 退出 | Ctrl+Q |
| 跳转到行 | Ctrl+G |

### 命令模式

```
:w      - 保存
:q      - 退出
:wq     - 保存并退出
:w file - 另存为
```

## 性能和限制

### 性能

- 启动时间：< 1 秒
- 编辑响应：实时
- 编译时间：取决于源文件大小
- 内存占用：< 50MB

### 限制

1. **文件大小**：建议 < 10000 行（curses 限制）
2. **编码**：仅支持 UTF-8
3. **终端**：需要支持 curses 的终端
4. **平台**：macOS、Linux（Windows 需要 WSL）
5. **并发**：一次只能编辑一个文件
