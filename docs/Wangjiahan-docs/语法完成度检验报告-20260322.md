| 语法域 | 代表规则 | AST 映射 | 结论 |

| 数组访问 | `variable -> IDENTIFIER id_varpart` | 嵌套 `ArrayAccessNode` | ✅ |

**对标结论**: ✅ **文法覆盖与 AST 契约一致**，无主干缺项。

## 3. 核心能力逐项验证

### 3.1 二义性处理（dangling else）

**实现策略**:
1. `%nonassoc LOWER_THAN_ELSE`
2. `%nonassoc ELSE`
3. `IF ... THEN statement %prec LOWER_THAN_ELSE`

**验证结论**: ✅ else 绑定最近 if，语义符合经典规则。

---

### 3.2 错误恢复能力

**实现策略**:
1. `statement_list ';' error` 作为恢复同步点
2. `yyerrok + yyclearin` 避免重复吞同一坏 token

**验证结论**: ✅ invalid 样例均可稳定报错并完成脚本级判定，无恢复死循环。

---

### 3.3 解析状态隔离

**实现点**:
1. `resetParseResult()` 清理 AST 根、Builder、规则位置缓存、错误计数
2. parse-only 与普通流程可重复调用 parser

**验证结论**: ✅ 多次执行解析无状态串扰。

---

### 3.4 语法错误可观测性

**实现点**:
1. `yyerror` 输出行列和词素
2. `getParseErrorCount()` 提供机器可读错误计数

**验证结论**: ✅ 人工定位与自动化脚本判定均可用。
