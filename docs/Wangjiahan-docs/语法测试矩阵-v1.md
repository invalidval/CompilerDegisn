## 4. 验收判定标准

1. 所有 `parser_valid` 用例退出码必须为 0。
2. 所有 `parser_invalid` 用例退出码必须非 0，且 stderr 中包含 `Parse error` 或 `Parsing failed`。
3. 语法回归脚本 `test/run_parser_tests.sh` 总退出码为 0 时，判定语法回归通过。

## 5. 验收结论

1. 本轮语法测试矩阵覆盖与回归执行结果一致。
2. 语法主干（声明、语句、表达式、过程/函数、数组）均通过回归验证。
3. 语法模块进入后续语义/代码生成联调阶段。

## 6. 说明

1. 当前脚本默认从 `./build/pascc` 取可执行文件。
