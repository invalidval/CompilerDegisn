# PASCC IDE 使用指南

## 简介

PASCC IDE 是一个轻量级的终端 IDE，专为 Pascal-S 编译器设计。它提供了代码编辑、语法高亮、实时编译和错误导航等功能。

## 特性

- **代码编辑器**：支持基本的文本编辑功能
- **语法高亮**：Pascal-S 关键字、注释、字符串、数字高亮
- **实时编译**：按 F5 即可编译当前文件
- **错误导航**：编译错误会高亮显示，自动跳转到第一个错误
- **快速运行**：按 F9 编译并运行程序
- **双面板布局**：左侧编辑器，右侧输出面板
- **行号显示**：带行号的代码显示
- **光标行高亮**：当前编辑行高亮显示

## 启动方式

### 方式 1：使用启动脚本

```bash
# 启动空白编辑器
bash scripts/run_ide.sh

# 打开指定文件
bash scripts/run_ide.sh test/close_set/00_main.pas
```

### 方式 2：直接运行 Python 脚本

```bash
# 启动空白编辑器
python3 scripts/pascc_ide.py

# 打开指定文件
python3 scripts/pascc_ide.py test/close_set/00_main.pas
```

## 快捷键

### 文件操作
- **Ctrl+S**：保存文件
- **Ctrl+O**：打开文件
- **Ctrl+Q**：退出 IDE

### 编辑操作
- **方向键**：移动光标
- **Home**：跳到行首
- **End**：跳到行尾
- **Page Up/Down**：翻页
- **Backspace**：删除前一个字符
- **Delete**：删除当前字符
- **Enter**：插入新行
- **Tab**：插入 4 个空格

### 导航
- **Ctrl+G**：跳转到指定行

### 编译和运行
- **F5**：编译当前文件
- **F9**：运行编译后的程序

### 输出面板
- **+/=**：向上滚动输出
- **-/_**：向下滚动输出

## 工作流程

### 1. 创建新文件

```bash
bash scripts/run_ide.sh
# 在 IDE 中按 Ctrl+S，输入文件名保存
```

### 2. 编辑现有文件

```bash
bash scripts/run_ide.sh test/close_set/00_main.pas
# 直接开始编辑
```

### 3. 编译和调试

1. 编写代码
2. 按 **Ctrl+S** 保存
3. 按 **F5** 编译
4. 查看右侧输出面板的编译结果
5. 如果有错误，编辑器会自动跳转到第一个错误行，错误行会用红色高亮
6. 修复错误后重新编译

### 4. 运行程序

1. 确保编译成功（按 F5）
2. 按 **F9** 运行程序
3. 在输出面板查看程序运行结果

## 语法高亮

IDE 支持以下语法高亮：

- **关键字**（蓝色）：`program`, `var`, `begin`, `end`, `if`, `while`, `for` 等
- **注释**（绿色）：`{ 这是注释 }`
- **字符串**（黄色）：`'hello'`
- **数字**（紫色）：`123`, `3.14`
- **当前行**（反色高亮）
- **错误行**（红色背景）

## 错误处理

### 编译错误

当编译出错时：
1. 错误行会用红色背景高亮
2. 光标自动跳转到第一个错误
3. 输出面板显示详细错误信息
4. 行号处显示红色标记

### 运行时错误

运行时错误会显示在输出面板中，包括：
- GCC 编译错误（如果生成的 C 代码有问题）
- 程序运行时的输出和错误

## 限制和注意事项

1. **终端大小**：建议至少 80x24 的终端窗口
2. **文件编码**：仅支持 UTF-8 编码
3. **自动保存**：IDE 不会自动保存，记得按 Ctrl+S
4. **撤销功能**：当前版本不支持撤销/重做
5. **多文件**：一次只能编辑一个文件

## 示例工作流

## 技术细节

### 架构

- **编辑器核心**：基于 Python curses 库
- **语法高亮**：简单的词法分析器
- **编译集成**：调用 `pascc` 命令行工具
- **错误解析**：解析编译器输出的错误格式

### 依赖

- Python 3.6+
- curses 库（通常预装在 Unix/Linux/macOS）
- pascc 编译器（需要先构建）

### 文件结构

```
scripts/
├── pascc_ide.py          # IDE 主程序
├── run_ide.sh            # 启动脚本
├── pascc_tui.py          # 原有的 TUI（编译可视化）
└── pascc_tui_interactive.py  # 交互式 TUI
```

## 故障排除

### 问题：IDE 无法启动

**解决方案**：
```bash
# 检查 Python 版本
python3 --version  # 需要 3.6+

# 检查脚本权限
chmod +x scripts/pascc_ide.py
chmod +x scripts/run_ide.sh
```

### 问题：编译失败

**解决方案**：
```bash
# 确保 pascc 已构建
bash scripts/build.sh

# 检查 pascc 是否可用
./build/pascc --help
```

### 问题：终端显示异常

**解决方案**：
- 调整终端窗口大小（至少 80x24）
- 使用支持 256 色的终端
- 尝试不同的终端模拟器（iTerm2, GNOME Terminal 等）

### 问题：无法输入中文

**说明**：当前版本仅支持 ASCII 字符输入，这是 curses 的限制。
