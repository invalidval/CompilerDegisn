# Pascal-S 编译器分工表

## 1. 分工总览
| 成员 | 角色 | 核心职责 | 主要输出 |
| :--- | :--- | :--- | :--- |
| A | 语法分析负责人 | AST 契约定义、Bison 建树动作、解析结果导出、模块联调 | AST 节点层级、建树接口、ProgramNode 根节点输出 |
| B | 组长/架构师 + 语义核心负责人 | 符号表实现、AST 语义注解、类型检查、语义错误处理 | SemanticAnnotator、类型检查规则、注解后的 AST |
| C | 词法分析负责人 | Flex 词法规则、Token 产出、行列号维护、词法错误检测 | Token 流、词法错误报告、词法测试用例 |
| D | 代码生成负责人（基础） | Visitor 基础遍历、基础语句生成、代码生成框架与单测 | CodeGenerator 基础 visit、generate(root) |
| E | 代码生成负责人（进阶） | 数组访问、过程调用、传引用参数、复杂节点代码生成 | ArrayAccess/ProcCall 等进阶 visit 实现 |

## 2. 统一接口清单
| 接口/结构 | 提供方 | 调用方 | 说明 |
| :--- | :--- | :--- | :--- |
| Token（含 type/value/line/col） | C | A | 词法输出，供语法分析消费 |
| ASTNode 基类与子类（含 NodeType/DataType/children/symbolEntry） | A | B、D、E | AST 统一契约 |
| buildTree(NodeType, children) | A | A、B | Bison 归约动作创建并链接节点 |
| ProgramNode* getParseResultRoot() | A | B、D、E、主流程 | 解析结束后返回根节点 |
| void annotate(ASTNode* root) | B | D、E | 填充类型、符号条目及语义属性 |
| string generate(ProgramNode* root) | D | 主流程 | 生成目标 C 代码入口 |
| visit(ArrayAccessNode*)、visit(ProcCallNode*) | E | D（同一生成器中协作） | 处理复杂节点与参数传递细节 |

## 3. 各角色职责

### A：语法分析
1. 定义 AST 层级与节点字段，确保和总体设计文档一致。
2. 在 parser.y 中将归约动作改为建树动作，不在语法阶段拼接 C 代码。
3. 输出 ProgramNode 根节点接口，供后续语义与代码生成调用。

### B：组长/架构师 + 语义核心
1. 实现符号表作用域管理与声明检查。
2. 实现 annotate(root) 深度优先注解流程。
3. 在 IdentifierNode、ProcCallNode、ArrayAccessNode 等节点写入语义信息。
4. 输出清晰语义错误信息（行号、列号、错误描述）。

### C：词法分析
1. 维护关键字、标识符、常量、界符规则。
2. 处理注释与空白，保证行列号准确。
3. 输出统一 Token 流给语法分析模块。
4. 提供词法错误测试样例与回归用例。

### D：代码生成（基础）
1. 实现 CodeGenerator::generate(root) 主入口。
2. 实现基础节点 visit（赋值、条件、复合语句等）。
3. 生成可编译 C 代码框架，并保留可扩展钩子。
4. 为基础 visit 编写单元测试。

### E：代码生成（进阶）
1. 实现 ArrayAccess 访问偏移逻辑（index - lower_bound）。
2. 实现 ProcCall 参数传递逻辑（按值/按引用）。
3. 读取语义注解字段（arrayBounds、paramInfo、symbolEntry）输出正确代码。
4. 在不改 parser 的情况下完成功能增强，验证前后端解耦。

## 4. 模块交接顺序（执行顺序）
1. C 先完成 Token 流稳定输出。
2. A 完成 AST 契约与 parser 建树并输出根节点。
3. B 基于根节点完成语义注解与错误检查。
4. D、E 基于已注解 AST 完成 Visitor 代码生成。
5. A 组织联调和集成测试，统一答辩演示版本。

## 5. 每人最小验收项
| 成员 | 最小验收项 |
| :--- | :--- |
| A | 能输出非空 ProgramNode 根节点，且关键语句节点可遍历到 |
| B | annotate 后关键节点 dataType/symbolEntry 有效，语义错误可定位 |
| C | 词法对关键字/标识符/常量识别正确，行列号准确 |
| D | generate(root) 可输出可编译的 C 程序骨架与基础语句 |
| E | 数组访问与过程调用（含 var 参数）生成逻辑正确 |
