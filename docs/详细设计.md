### 4.3 Token 识别算法

#### 4.3.1 标识符处理 (src/lexer.l:428-446)

```c
{ID_START}{ID_CONT}*  {/* 匹配标识符模式 */
    std::string lowered = toLower(yytext, yyleng);  // 统一转小写

    // 检查长度限制（255字符）
    if (yyleng > MAX_IDENTIFIER_LENGTH) {
        reportLexError(g_token_line, g_token_column, "Identifier too long", yytext);
        continue;
    }

    // 查找关键字
    auto it = g_keyword_tokens.find(lowered);
    if (it != g_keyword_tokens.end()) {
        yylval.text = nullptr;  // 关键字不需要文本
        setTokenMeta("Keyword", "keyword");
        return it->second;  // 返回关键字 Token
    }

    // 普通标识符
    yylval.text = duplicateText(lowered.c_str());
    setTokenMeta("Identifier", "identifier");
    return IDENTIFIER;
}
```

#### 4.3.2 注释处理（支持嵌套）

```c
<INITIAL>"{" {/* 进入注释状态 */
    g_in_comment = true;
    g_comment_depth = INITIAL_COMMENT_DEPTH;
    g_comment_start_line = g_line;
    g_comment_start_column = g_column;

}

<COMMENT>"{" {/* 嵌套注释 */

<COMMENT>"}" {/* 退出一层注释 */}
```

```cpp
void advancePosition(const char* text, int len) {
    for (int i = 0; i < len; ++i) {
        if (text[i] == '\n') {
            ++g_line;        // 遇到换行，行号加1
            g_column = 1;     // 列号重置为1
        } else {
            ++g_column;       // 否则列号加1
        }
    }
}
```

```cpp
// 辅助函数：从范围构建数组类型
ASTNode* buildArrayTypeFromRanges(ASTNode* rangesNode, ASTNode* elemType, SourcePos pos) {
    if (rangesNode == nullptr || rangesNode->nodeType != NodeType::List) {
        return elemType;
    }

    auto* ranges = static_cast<ListNode*>(rangesNode);
    ASTNode* current = elemType;

    // 反向遍历，构建嵌套的数组类型
    for (int i = static_cast<int>(ranges->children.size()) - 1; i >= 0; --i) {
        ASTNode* seg = ranges->children[static_cast<size_t>(i)];
        if (seg == nullptr || seg->nodeType != NodeType::ArrayType || seg->children.size() < 2) {
            continue;
        }
        current = g_astBuilder.makeArrayType(seg->children[0], seg->children[1], current, pos);
    }
    return current;
}
```

### 5.5 错误恢复策略

#### 5.5.1 恐慌模式恢复

Bison 默认的 panic mode 错误恢复策略：
- 遇到语法错误时，丢弃输入直到找到同步符号
- 同步符号包括：分号、BEGIN、END、括号等

```cpp
const SymbolEntry* SymbolTable::lookup(const std::string& name) const {
    const std::string normalized = normalizeName(name);
    for (auto it = scopes_.rbegin(); it != scopes_.rend(); ++it) {
        auto found = it->find(normalized);
        if (found != it->end()) {
            return found->second;
        }
    }
    return nullptr;
}
```

#### 7.4.2 插入算法

```cpp
bool SymbolTable::insert(SymbolEntry entry) {
    entry.name = normalizeName(entry.name);
    auto& current = scopes_.back();
    if (current.find(entry.name) != current.end()) {
        return false;
    }
    entry.scopeLevel = currentScopeLevel();
    entryArena_.push_back(std::make_unique<SymbolEntry>(std::move(entry)));
    const SymbolEntry* stored = entryArena_.back().get();
    current[stored->name] = stored;
    return true;
}
```

```cpp
std::vector<ArrayBound> SemanticAnnotator::collectArrayBounds(ASTNode* typeNode) const {
    std::vector<ArrayBound> bounds;
    ASTNode* cur = typeNode;

    while (cur != nullptr && cur->nodeType == NodeType::ArrayType) {
        if (cur->children.size() < 3) break;

        int lower = 0, upper = -1;
        if (tryEvalIntConst(cur->children[0], lower) &&
            tryEvalIntConst(cur->children[1], upper)) {
            bounds.push_back({lower, upper});
        }

        cur = cur->children[2];
    }
    return bounds;
}
```

```cpp
bool SemanticAnnotator::tryEvalIntConst(ASTNode* node, int& out) const {
    if (node == nullptr) return false;

    if (node->nodeType == NodeType::Literal) {
        char* end = nullptr;
        long result = std::strtol(
            static_cast<LiteralNode*>(node)->value.c_str(), &end, 10);
        if (*end == '\0') {
            out = static_cast<int>(result);
            return true;
        }
    }

    // 支持一元表达式和二元表达式的编译期计算
    return false;
}
```

```cpp
void SemanticAnnotator::annotateTypeDecl(TypeDeclNode* node) {
    // 注解类型定义（record 类型）
    if (node->children.size() > 0) {
        annotateNode(node->children[0]);
    }

    // 收集 record 字段信息
    std::vector<std::pair<std::string, DataType>> fields;
    if (node->children[0]->nodeType == NodeType::RecordType) {

}
```

#### 8.7.2 字段访问注解

```cpp
void SemanticAnnotator::annotateFieldAccess(FieldAccessNode* node) {
    // 注解基础表达式
    if (node->children.size() > 0) {
        annotateNode(node->children[0]);
        ASTNode* base = node->children[0];

        // 检查基础表达式是否为 record 类型
        if (base->dataType != DataType::Record) {
            errorHandler_.report(node->pos.line, node->pos.column,
                "Field access requires record type");
            node->dataType = DataType::Unknown;
            return;
        }

        // 查找字段类型
        if (base->symbolEntry && !base->symbolEntry->recordFields.empty()) {
            for (const auto& field : base->symbolEntry->recordFields) {
                if (field.first == node->fieldName) {
                    node->dataType = field.second;
                    node->isLValue = true;
                    return;
                }
            }
            errorHandler_.report(node->pos.line, node->pos.column,
                "Field '" + node->fieldName + "' not found in record");
        }
    }
    node->dataType = DataType::Unknown;
}
```

#### 8.7.3 字段信息收集

```cpp
std::vector<std::pair<std::string, DataType>>
SemanticAnnotator::collectRecordFields(ASTNode* recordTypeNode) const {
    std::vector<std::pair<std::string, DataType>> fields;

    if (recordTypeNode == nullptr || recordTypeNode->nodeType != NodeType::RecordType) {
        return fields;
    }

    // 遍历字段声明列表
    for (ASTNode* child : recordTypeNode->children) {
        if (child->nodeType == NodeType::FieldDecl && child->children.size() >= 2) {
            ASTNode* idList = child->children[0];
            ASTNode* typeNode = child->children[1];
            DataType fieldType = inferTypeFromNode(typeNode);

            // 收集所有字段名
            if (idList->nodeType == NodeType::List) {
                for (ASTNode* idNode : idList->children) {
                    if (idNode->nodeType == NodeType::Identifier) {
                        std::string fieldName = static_cast<IdentifierNode*>(idNode)->name;
                        fields.push_back({fieldName, fieldType});
                    }
                }
            }
        }
    }

    return fields;
}
```

```cpp
        default:                return "int";
    }
}
```

### 9.5 表达式生成

#### 9.5.1 二元表达式

```cpp
void CodeGenerator::visit(BinaryExprNode* node) {
    std::string lhs = emitNode(node->children[0]);
    std::string rhs = emitNode(node->children[1]);
    std::string op = node->op;

    if (op == "mod") op = "%";
    else if (op == "div") op = "/";
    else if (op == "=") op = "==";
    else if (op == "<>") op = "!=";
    else if (op == "and") op = "&&";
    else if (op == "or") op = "||";

    currentExpr_ = "(" + lhs + " " + op + " " + rhs + ")";
}
```

#### 9.5.2 一元表达式

```cpp
void CodeGenerator::visit(UnaryExprNode* node) {
    std::string operand = emitNode(node->children[0]);

    if (node->op == "not") {
        currentExpr_ = "(!" + operand + ")";
    } else {
        currentExpr_ = "(" + node->op + operand + ")";
    }
}
```

### 9.6 数组下标偏移处理

```cpp
void CodeGenerator::visit(ArrayAccessNode* node) {
    std::string base = emitNode(node->children[0]);
    std::string index = emitNode(node->children[1]);

    int lowerBound = node->lowerBound;
    if (node->symbolEntry != nullptr && node->symbolEntry->isArray) {
        const int depth = arrayAccessDepthForCodegen(node);
        if (depth >= 0 && static_cast<size_t>(depth) < node->symbolEntry->arrayBounds.size()) {
            lowerBound = node->symbolEntry->arrayBounds[static_cast<size_t>(depth)].lower;
        }
    }

    if (lowerBound == 0) {
        currentExpr_ = base + "[" + index + "]";
    } else {
        currentExpr_ = base + "[(" + index + ") - " + std::to_string(lowerBound) + "]";
    }
}
```

### 9.7 var 参数处理

#### 9.7.1 过程原型声明

```cpp
std::string CodegenUtils::emitProcPrototype(ProcDeclNode* node) {
    std::ostringstream oss;
    oss << "void " << node->name << "(";

    bool first = true;
    for (const ParamInfo& p : params) {
        if (!first) oss << ", ";
        first = false;

        std::string ctype = mapType(p.type);
        if (p.isVarParam) {
            oss << ctype << " *";
        } else {
            oss << ctype << " ";
        }
        oss << p.name;
    }

    oss << ")";
    return oss.str();
}
```

```cpp
for (size_t i = 0; i < node->children.size(); ++i) {
```

```cpp
std::string CodegenUtils::emitReadStmt(ProcCallNode* node) {
    std::ostringstream oss;
    oss << "scanf(\"";

    std::vector<std::string> args;
    for (ASTNode* arg : node->children) {
        DataType t = inferArgumentType(arg);
        oss << getFormatSpecifier(t);

        std::string expr = codeGen.emitNode(arg);
        args.push_back("&" + expr);
    }

    for (const auto& a : args) oss << ", " << a;
    oss << ");";
```

```cpp
std::string CodegenUtils::emitWriteStmt(ProcCallNode* node) {
    std::ostringstream oss;
    oss << "printf(\"";

    std::vector<std::string> args;
    for (ASTNode* arg : node->children) {
        DataType t = inferArgumentType(arg);
        oss << getFormatSpecifier(t);

        std::string expr = codeGen.emitNode(arg);
        if (t == DataType::Real && arg->dataType == DataType::Integer) {
            expr = "(float)(" + expr + ")";
        }
        args.push_back(expr);
    }

    oss << "\"";
    for (const auto& a : args) oss << ", " << a;
    oss << ");";

    return oss.str();
}
```

### 9.9 Record 类型代码生成（扩展）

#### 9.9.1 类型声明生成

```cpp
void CodeGenerator::visit(TypeDeclNode* node) {
    // 生成 typedef struct 声明
    if (node->children.size() > 0 && node->children[0]->nodeType == NodeType::RecordType) {
        std::ostringstream oss;
        oss << "typedef struct {\n";

        // 遍历字段声明
        RecordTypeNode* recordNode = static_cast<RecordTypeNode*>(node->children[0]);
        for (ASTNode* fieldDecl : recordNode->children) {
            if (fieldDecl->nodeType == NodeType::FieldDecl && fieldDecl->children.size() >= 2) {
                ASTNode* idList = fieldDecl->children[0];
                ASTNode* typeNode = fieldDecl->children[1];

                std::string cType = mapType(typeNode->dataType);

                // 为每个字段生成声明
                if (idList->nodeType == NodeType::List) {
                    for (ASTNode* idNode : idList->children) {
                        if (idNode->nodeType == NodeType::Identifier) {
                            std::string fieldName = static_cast<IdentifierNode*>(idNode)->name;
                            oss << "    " << cType << " " << fieldName << ";\n";
                        }
                    }
                }
            }
        }

        oss << "} " << node->typeName << ";\n";
        globalDecls_ += oss.str();
    }
}
```

#### 9.9.2 字段访问生成

```cpp
void CodeGenerator::visit(FieldAccessNode* node) {
    // 生成字段访问表达式：record.field
    if (node->children.size() > 0) {
        std::string base = emitNode(node->children[0]);
        currentExpr_ = base + "." + node->fieldName;
    }
}
```

### 11.2 编译流程控制

```cpp
int main(int argc, char *argv[]) {
    std::string inputPath, outputPath;
    bool lexMode = false, parseOnly = false, semanticOnly = false;

    parseArgs(argc, argv, inputPath, outputPath, lexMode, parseOnly, semanticOnly, ...);

    FILE *input = std::fopen(inputPath.c_str(), "r");
    yyin = input;
    lexerResetState();

    if (lexMode) {
        runLexMode(dumpTokens);
    } else {
        resetParseResult();
        if (yyparse() != 0) {
            std::cerr << "Parsing failed.\n";
            return 1;
        }

        ProgramNode *root = getParseResultRoot();

        SymbolTable symbolTable;
        semantic_register::preregisterBuiltins(symbolTable);
        ErrorHandler errorHandler;
        SemanticAnnotator annotator(symbolTable, errorHandler);
        annotator.annotate(root);

        if (errorHandler.hasErrors()) {
            for (const auto &err : errorHandler.errors()) {
                std::cerr << "Error at " << err.line << ":" << err.column << " - " << err.message << "\n";
            }
            return 1;
        }

        CodeGenerator generator;
        std::string cCode = generator.generate(root);

        std::ofstream out(outputPath);
        out << cCode;
    }

    std::fclose(input);
    return 0;
}
```

3. 语义分析（SemanticAnnotator）→ 注解 AST
4. 代码生成（CodeGenerator）→ C 代码
5. 输出文件生成

## 13. 与总体设计的差异说明

### 13.1 实现与设计的重要差异

| 项目 | 总体设计 | 实际实现 |
|------|----------|----------|
| 符号表作用域 | 最多 2 层 | 最多 2 层（全局 + 局部）|
| 注释支持 | 可选嵌套 | 完全支持嵌套 |
| 标识符转换 | 统一小写 | 统一小写 |
| 数组下标 | 运行时偏移 | 生成 `a[(i) - lower]` |
| var 参数 | 指针传递 | 声明为 `int*`，调用 `&`，使用 `*` |
| 内存管理 | Arena 模式 | unique_ptr 向量 |
| 代码分区 | 4 个区域 | 4 个 string 成员 |

### 13.2 代码实现优于设计的方面

1. **编译期边界检查**：collectArrayBounds() 和 tryEvalIntConst() 实现了编译期常量计算
2. **嵌套注释支持**：使用 g_comment_depth 深度计数器
3. **详细位置跟踪**：YY_USER_ACTION 宏自动更新行列信息
4. **内存安全**：entryArena_ 保证符号指针稳定性

### 13.3 Record 类型扩展（新增特性）

Record 类型是在基础设计完成后新增的扩展特性，涉及以下模块的修改：

| 模块 | 扩展内容 |
|------|----------|
| 词法分析 | 新增 `type` 和 `record` 关键字 |
| 语法分析 | 新增类型声明、record 类型、字段声明、字段访问等产生式 |
| AST 节点 | 新增 TypeDecl、RecordType、FieldDecl、FieldAccess 节点类型 |
| 符号表 | 新增 TypeAlias 符号种类，新增 recordFields 和 recordTypeName 字段 |
| 语义分析 | 新增类型声明注解、字段访问检查、字段信息收集等功能 |
| 代码生成 | 新增 typedef struct 生成、字段访问表达式生成 |

**设计原则**：
1. 最小化侵入性：扩展不影响原有功能
2. 类型安全：字段访问需要类型检查和字段存在性检查
3. 代码映射：Pascal record 直接映射为 C typedef struct
4. 左值语义：字段访问表达式可作为赋值左值
