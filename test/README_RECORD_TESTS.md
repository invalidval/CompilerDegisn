# Record 类型测试脚本使用说明

## 脚本功能

`run_record_tests.sh` 用于批量自动执行 `test/cases/record/` 目录下的所有 record 类型测试用例。

## 测试流程

对每个 `.pas` 文件，脚本会：

1. **Pascal → C 编译**: 使用 `pascc` 编译器将 `.pas` 文件编译为 `.c` 文件
2. **C → 可执行文件**: 使用 `gcc` 编译生成的 C 代码
3. **运行测试**: 执行生成的可执行文件（5秒超时）
4. **记录结果**: 保存所有编译输出和运行结果

## 使用方法

```bash
# 在项目根目录下运行
bash test/run_record_tests.sh

# 或在 test 目录下运行
cd test
bash run_record_tests.sh
```

## 输出文件

所有测试结果保存在 `test/record_test_results/` 目录：

- `test_results_YYYYMMDD_HHMMSS.txt`: 完整测试报告（带时间戳）
- `summary.txt`: 最新测试摘要
- `<testname>_compile.log`: Pascal 编译日志
- `<testname>_gcc.log`: GCC 编译日志
- `<testname>_output.log`: 程序运行输出

## 测试报告内容

每个测试用例包含：

- 源文件路径
- Pascal 编译结果和输出
- C 编译结果
- 程序运行结果和输出
- 状态标识（✓ 成功 / ✗ 失败）

## 统计信息

测试完成后显示：

- 总测试数
- 通过数量
- 失败数量
- 编译错误数量
- 成功率

## 退出码

- `0`: 所有测试通过
- `1`: 存在失败或编译错误的测试

## 注意事项

1. 运行前需要先构建编译器：`bash scripts/build.sh`
2. 脚本会自动创建输出目录
3. 每次运行生成新的带时间戳的结果文件
4. 程序运行超时设置为 5 秒
5. 需要安装 `gcc` 和 `timeout` 命令
